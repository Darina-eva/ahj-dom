# DOM: перемещение элемента

Игровое поле 4x4, на котором гоблин (`img`) появляется в случайной клетке и каждую секунду через `setInterval` перемещается в другую случайную клетку (не в ту же самую). Перемещение делается сменой родителя узла, без `removeChild`. Сборка — Webpack (картинки и стили тоже), CI/CD — GitHub Actions + GitHub Pages.
